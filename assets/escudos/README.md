# Escudos

Coloque aqui as imagens dos escudos (PNG ou SVG), com o nome do clube sem acentos,
em minúsculas e com hífens. Exemplos: `flamengo.png`, `sao-paulo.png`, `atletico-goianiense.png`.

Depois cadastre cada imagem em `js/data/crests.js`:

```js
'Flamengo': { src: 'assets/escudos/flamengo.png', colors: ['#c8102e', '#111111'] },
```

As cores são opcionais. Quando informadas, a camisa do jogador passa a usar essas cores.
